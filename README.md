# Nákupný jedálniček

Webová aplikácia na plánovanie jedál podľa rozpočtu: jedálniček na niekoľko dní, nákupný zoznam s bežnými cenami (Lidl, Kaufland, Tesco, Billa), recepty a výživové hodnoty.
Funguje offline a dá sa nainštalovať do mobilu („Pridať na plochu“).

**Aplikácia:** https://samkowww.github.io/jedalnicek/

## Súbory
- `index.html` – celá aplikácia (suroviny a ceny, recepty, logika, vzhľad)
- `manifest.webmanifest`, `sw.js`, ikony – inštalácia do mobilu a offline režim

Ceny sú bežné (nie akciové): Lidl, Kaufland a Tesco podľa cenyslovensko.sk (7/2026) a Tesco online (11/2026), Billa je odhad.
